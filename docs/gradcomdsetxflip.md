# **set xflip**

`set xflip `*`on|off`*

Flips the order of the horizontal axis (whatever axis is horizontal after <a href="gradcomdsetxyrev.html">`xyrev`</a> is applied). Reset by a `clear` or <a href="gradcomdsetvpage.html">`set vpage`</a> command.
