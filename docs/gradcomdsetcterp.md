# **set cterp**

`set cterp `*`on|off`*

Turns spline smoothing on or off. "Sticks" until reset. Shaded contours are drawn without spline fitting, so to insure an exact match when overlaying contour lines and shaded contours of the same field, specify `cterp` as off. You can still use the <a href="gradcomdsetcsmooth.html">`csmooth`</a> option, which affects both contour lines and shaded contours.
