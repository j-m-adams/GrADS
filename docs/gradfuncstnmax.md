# **stnmax**

`stnmax(`*`expr,dexpr1,dexpr2<,-m cnt`*`)`

Examines a time series of station data and returns the maximum value encountered for each station. Operands and usage are the same as the <a href="gradfuncstnave.html">`stnave`</a> function.
