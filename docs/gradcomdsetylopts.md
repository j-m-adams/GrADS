# **set ylopts**

`set ylopts `*`color <thickness <size>>`*

Controls aspects of axis display

- `ylopts`               controlsthe Y Axis\
  *`color`*                  Label color (Default 1)\
  *`thickness`*          Label thickness (Default 3)\
  *`size`*                    Label size (Default 0.11)
