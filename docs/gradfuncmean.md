# **mean()**

`mean (`*`expr, dexpr1, dexpr2, <,tinc>`*` <,-b>)`

This function is the same as <a href="gradfuncave.html">`ave`</a> in all respects except one: means in the Y dimension ***are not*** weighted by latitude. The means ***are*** weighted by grid interval to account for non-linear grid spacing.

## Usage Notes

1.  See the <a href="gradfuncave.html">`ave`</a> reference page for details.
