# **set annot**

`set annot `*`color`*` <`*`thickness`*`>`

Sets `color` and line*`thickness`*.

## Usage Note

Default is `white`, thickness `6`. This commandalso sets the *`color`* and*`thickness`* for the axis border, axis labels, andtickmarks. Axis tickmarks and labels are plotted at the specifiedthickness minus 1.
