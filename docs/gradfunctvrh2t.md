# **tvrh2t**

`tvrh2t(`*`tvexpr,rhexpr`*`)`

Given virtual temperature and relative humidity, `tvrh2t` returns the temperature in degrees Kelvin. The operation of this function is the same as <a href="gradfunctvrh2q.html">`tvrh2q`</a>; refer to the above description for more information.
