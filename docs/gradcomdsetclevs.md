# **set clevs**

`set clevs `*`lev1 lev2 lev3 ... levN`*

Sets specific contour levels.

## Usage Notes

1.  Contour levels are reset with every execution of <a href="gradcomdclear.html">`clear`</a> or <a href="gradcomddisplay.html">`display`</a>.
2.  `set clevs` is often used with <a href="gradcomdsetccols.html">`set ccols`</a> to override the default settings and specify exact contour levels and the colors that go with them.
3.  See section of User's Guide on <a href="colorcontrol.html">controlling colors in Grads</a> for more details.
