# **draw string**

`draw string `*`x y string`*

Draws the character `string` at the *`x,y`* position. *`x`* and` `*`y`* are given in inches on the virtual page. The string is drawn using current string attributes -- set the <a href="gradcomdsetstring.html">`set string`</a> and <a href="gradcomdsetstrsiz.html">`set strsiz`</a> commands.
