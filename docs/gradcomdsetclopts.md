# **set clopts**

`set clopts `*`color <thickness <size>>`*

- *`color`*            isthe labelcolor. `-1` isthe default, and indicates to use the contour line color as the labelcolor\
  *`thickness`*    is the labelthickness. `-1` isthe default.\
  *`size`*              isthe label size. `0.09` is thedefault

This setting stays set until changed by issuing another `setclopts` command.
