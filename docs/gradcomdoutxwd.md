# **outxwd**

This command dumps the contents of the graphics window to a file. The output file is in XWD (X Windows Dump) format. The syntax is:

- `outxwd `*`filename`*

where *`filename`* is the name of the XWD file.

## Usage Notes

The <a href="gradcomdprintim.html">`printim`</a> command may also be used for creating image output in other formats.

This command does not work in batch mode, or in version 2.1+ when Cairo is enabled.
