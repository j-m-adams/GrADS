# **set xlopts**

`set xlopts `*`color <thickness <size>>`*

Controls aspects of axis display

- `xlopts`            controlsthe X Axis\
  *`color`*              Labelcolor (Default 1)\
  *`thickness`*      Labelthickness (Default 3)\
  *`size`*                Label size (Default 0.11)
