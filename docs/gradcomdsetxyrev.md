# **set xyrev**

`set xyrev `*`on|off`*

Reverses the axes on a plot.

## Usage Notes

### Examples

By default for a Z, T plot, the time dimension is plotted horizontally, and the Z dimension is plotted vertically. By setting `xyrev`, the time dimension would be plotted vertically and the Z dimension would be plotted horizontally. Reset by a `clear` or <a href="gradcomdsetvpage.html">`set vpage`</a> command.
