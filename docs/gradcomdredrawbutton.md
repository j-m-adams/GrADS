# **redraw button**

`redraw button `*`num state <flag> <text>`*

`0|1`Redraws button number *`num`* to either the `"ON"` state `(1)`or `"OFF"` state `(0)`.

num is the button number, which can be between 1 and 255

state is either `"ON"` `(1)` or `"OFF"``(0)`.
