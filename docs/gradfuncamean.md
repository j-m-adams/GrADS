# **amean()**

`amean (`*`expr, xdim1, xdim2, ydim1, ydim2`*`)`

This function is the same as <a href="gradfuncaave.html">`aave`</a> in all respects except one: area means ***are not*** weighted by latitude. Means ***are*** weighted by grid interval to account for non-linear grid spacing.

## Usage Notes

See the <a href="gradfuncaave.html">`aave`</a> reference page for details.
