# **hdivg**

`hdivg(`*`uexpr,vexpr`*`)`

Calculates the horizontal divergence using finite differencing. Exactly the same as <a href="gradfunchcurl.html">`hcurl`</a> in all other respects; see the Usage Notes and Examples above.

## Usage Notes

1.  The numerical stability of calculating horizontal divergence using finite differencing is very low. Please use the function with caution.
