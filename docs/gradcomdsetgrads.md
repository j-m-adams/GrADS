# **set grads**

`set grads `*`on`*`|`*`off`*

This command turns on/off the display of the GrADS logo and the time label for sreen and printed output.

## Usage Notes

1.  The default is *`on`* and is reset by <a href="gradcomdclear.html">`clear`</a>.
2.  To turn off only the time label, use <a href="gradcomdsettimelab.html">`set timelab`</a>.
