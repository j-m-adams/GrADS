# **atan2()**

`atan2 (`*`expr1, expr2`*`)`

Applies the tan<sup>-1</sup> function to the result of (*`expr1/expr2`*).

If *`expr1`* and *`expr2`* are both zero, the result is arbitrarily set to zero. The result of the `atan2` function is in radians.
