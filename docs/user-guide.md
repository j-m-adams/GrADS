## General topics

Start with <a href="user-guide-general.html">GrADS fundamentals and data

## Analysis topics

Learn how to <a href="user-guide-analysis.html">select, transform, and analyse

## Display topics

Use the <a href="user-guide-display.html">display and graphics guide</a> for
plots, maps, shapefiles, colours, fonts, animation, page layout, and image

## Scripting and extensions

Automate and extend GrADS with the <a href="user-guide-scripting.html">scripting
and extension guides</a>, including GrADS scripts, Python, plug-ins, and
