# **sumg()**

`sumg (`*`expr, dexpr1, dexpr2, <,tinc>`*` <,-b>)`

This function is the same as <a href="gradfuncsum.html">`sum`</a> in all respects except one: the sums are calculated without any weighting at all.

## Usage Notes

1.  See the <a href="gradfuncsum.html">`sum`</a> reference page for details.
