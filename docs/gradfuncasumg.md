# **asumg()**

`asumg(`*`expr, xdim1, xdim2, ydim1, ydim2`*`)`

This function is the same as <a href="gradfuncasum.html">`asum`</a> in all respects except one: the sums are calculated without any weighting at all.

## Usage Notes

1.  See the <a href="gradfuncasum.html">`asum`</a> reference page for details.
